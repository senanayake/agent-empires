# MVP definition of done

All items start unchecked. Planning artifacts and controller validation do not
constitute MVP completion. Detailed criteria and activity references live in
[campaign section 12](mvp-campaign.md#12-mvp-definition-of-done).

- [ ] **D01:** PaymentCo: five departments, about ten starting humans, up to three
  agent profiles, six distributed decisions and the incomplete retry Work Item.
- [ ] **D02:** Visible speed/cost gains make automation tempting; shared Actor rules.
- [ ] **D03:** Function/knowledge/path loss causes explainable differences; closure,
  authority and evidence remain distinct; green output is not global correctness.
- [ ] **D04:** Automate, clarify, document, connect and ship change Python state;
  implementation, interpretation and outcome learning loops are demonstrated.
- [ ] **D05:** Reproducible benign/harmful assumptions, wrong authorized policy,
  human failure and successful fully agent-operated organization.
- [ ] **D06:** Natural delayed outcomes, discoverable causal inspection, and no
  actor-kind punishment or hidden-world information leakage.
- [ ] **D07:** Actual 15–20-minute formative sessions meet the comprehension and
  voluntary-strategy-retry criteria in AE-029, with material revisions retested.
- [ ] **D08:** Pinned deterministic histories, frame-independent outcomes, and
  uninterrupted-versus-resumed equivalence.
- [ ] **D09:** Independent Python core; offline local packaged Godot build on an
  explicitly tested platform with no external LLM dependency.
- [ ] **D10:** Assumptions, provenance, sensitivity, ADR status, measured runtime
  bounds, failed hypotheses and unsupported claims accompany the build.

AE-035 records exact evidence references and any unmet items in
`docs/mvp-validation.md`. Changes to this checklist require rationale and must not
silently relax a failed player-comprehension or scientific-integrity gate.
