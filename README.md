# agent-empires
Strategize. Build your empire. Control your agents.

Agent Empires is a 2D management simulation about how organizations turn uncertain
intent into decisions, software, outcomes, and learning.

Start with the [MVP development campaign](docs/mvp-campaign.md). It defines the
risk-ordered activities, evidence gates, and scope for PaymentCo. The
[Campaign Controller handoff](docs/campaigns/mvp/README.md) explains how to inspect
and later execute its queue. The repository currently contains planning artifacts;
the simulation and Godot game have not been implemented.
