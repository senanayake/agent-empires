# AE-015 paired model gate protocol

Saved before execution or analysis. Reviewer: assigned Codex worker self-review;
controller execution is separate. Question: do causal exposure, separate decision
axes and three finite learning loops survive combined paired model challenges?
No architecture acceptance, real payments recommendation or participant study.

Predeclare root seeds 0 through 29 inclusive, worlds world_a/world_b, and strategies
infer/clarify/feedback. Thirty is a bounded exploration choice, not a power analysis.
Generate one immutable workload per world/seed with eight arrival ticks using the
existing named RNG scheme. Reuse every potential ordinal draw across strategies,
policy probes and parameter alternatives. Hold categories fixed for sensitivity;
across authored worlds the same keyed uniforms meet different category cutoffs.
All actors use matched profiles/holdings/grants; primary runs relabel the entire
roster as agents. Relabel every strategy to humans at seed zero in both worlds.

Infer selects new-key idempotency and Priya's authorized blanket no-decline policy,
with three fixed-delay retries, all failure classes and lineage audit. No selection
counts as evidence. Clarify adds a real reliable Ada request/response over one-tick,
one-message-per-tick channels (one resource unit each direction, one service tick,
12-tick timeout), then selects the received stable-key claim without inheriting
Ada's authority or adding independently backed evidence. Feedback starts with the
infer choices, fixes an authored omitted-retry implementation defect (retaining
all decisions), deploys and observes the old policy, then revises idempotency using
an accessible current independent interface report. That report is explicitly
trusted authored input; physical feedback alone does not reveal a correct remedy.

The feedback experiment also exposes stable-key blocked/soft-only policy probes
to the same workload in separate application instances. Recommendations use only
recorded completed-cohort observations: prefer soft_only if abandonment is strictly
lower, otherwise retain do_not_retry (ties minimize retry expenditure). This is a
bounded intervention comparison, not autonomous alternative discovery or an actor
reading hidden world parameters. Only a conclusive old observed miss and a soft
recommendation permit Priya's policy revision. Always deploy the future artifact
and assess it separately; no remedy is presumed to meet the goal. Preserve prefixes,
old deployment pins and the replacement's unsupported fitness at enactment.

Sensitivity: old-cohort assessments use minima 1/4/12 operations, miss margins
0/0.2/0.4 rates and complete/missing-last/copied-first evidence structures. These
are toy MA-09 rules, not significance thresholds. Missing samples must stay pending;
copies cannot increase sample count. Re-run feedback at every seed/world with
recovery readiness 3 instead of 1 tick and with monitoring lag 0 instead of the
scenario value. Preserve workload bytes. Monitoring changes observation timing,
not physical results or recommendation; readiness may change recommendations.
No new outcome/learning rules are introduced in the harness.

Metrics remain separate: closure count, current authority gaps (ungranted choices),
backed source coverage and learning records; completed operations and completed per
physical terminal tick; ship/final observation delay; duplicate charges, abandonment,
retry cost and audit coverage; finite observed fitness status/rate. Feedback's old
and future cohorts are separate, never aggregated into a better-looking rate.
Report each seed, each paired difference, mean/min/max and counts of pending,
unknown/fail/pass. Ranges are descriptive across 30 toy seeds, not confidence
intervals. Retain incident-free inference, recommendation ties/reversals, failed
future goals and unchanged policies. No composite morality or debt scalar.

Analytical controls: no traffic => pending fitness/no incident; all recoverable
transients => completed; hard declines => abandon; ambiguous hidden execution =>
new-key duplicate versus stable-key protection; soft recovery zero/one with the
same draws reverses the observed policy recommendation; four successful autonomous
soft operations after authorized revision; mistaken human authority fails before
revision; incomplete/copy feedback stays pending; unsupported transient inference
can be harmless. Exact rate boundary cases 10 operations with 1/2/3 abandoned
must be pass/unknown/fail under target 0.1 and margin 0.2.

Gate: pass for bounded consistency if actor-kind invariance, sample pairing,
separate learning objects, expected boundaries and world-dependent recommendation
survive; narrow/replan if those controls fail; stop if a pass requires tuning toy
parameters, unsupported calibration or synthetic human evidence. Negative fitness
is a research result, not an engineering-control failure. Consider all dispositions
in decision.md. Adopt AE-014 removal of scalar from planned gameplay unless new
counterevidence exists; retain its API for historical reproduction only.

Artifacts: protocol.json (explicit settings and provenance), manifest.json (runtime,
model/source/protocol hashes, workload samples and result hash), results.json (all
arms, probes, sensitivity, boundaries and representative seed-zero histories),
timing.json, raw red/green/check outputs and decision.md. Author refuses existing
canonical/timing files and saves protocol first. Verify reruns in temporary storage,
compares canonical JSON and manifest hashes without overwriting reviewed evidence,
and checks a fresh 120-second wall budget within the 300-second command timeout.
Timing bytes are not canonical results. CPython 3.12.13, locked uv environment.
